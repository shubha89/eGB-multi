## Implementation decisions to settle first

For a fixed injection, vary the circular template while preserving the injection parameters. Candidate circular parameters include GW carrier frequency, frequency derivative, sky latitude/longitude, amplitude, inclination, polarization, and initial phase. The implemented 1PN circular limit must be checked before treating component masses as purely redundant amplitude parameters. The eccentric model's parameter count is not automatically the number of independent circular parameters.

Define overlap as the normalized real noise-weighted inner product. Define match through the intended phase/time maximization, and fitting factor through further maximization over the circular family. For long-lived LISA signals, distinguish a change of source reference epoch from shifting a detector time series: the detector response is tied to absolute observation times. Test any claimed degeneracy with phase and frequency instead of assuming a generic arrival-time shift.

Use common physical amplitude/phase/polarization coefficients across A and E. Independently fitting the two channels would enlarge the template family beyond one coherent circular source. If an analytic amplitude basis is used, retain its full noise-weighted Gram matrix; orthogonal, equal-norm quadratures must be demonstrated before using a simplified complex-correlation magnitude.

Scale frequency and chirp search coordinates using the observation duration, for example frequency offset times T and frequency-derivative offset times T squared. Record periodic angle conventions, physically allowed domains, parameter bounds, and the source-frequency reference epoch. Include the original candidate templates as search seeds. An expanded search cannot reduce the best objective value when the objective, injection, candidate set, and numerical settings are held fixed; changes to the original metric must be assessed separately.

Use one fixed physical analysis band and injection norm throughout each search, including searches around different harmonics. Include all harmonics carrying relevant noise-weighted signal power and their response/precession/chirp broadening. Changing the normalization band for each candidate would change the comparison being optimized.

Figures 5 and 6 may intentionally compare waveforms at the same physical parameters to isolate model corrections. Preserve that purpose and label the corresponding overlap or model discrepancy accurately. Optimize the circular-recovery comparison rather than silently changing every source-correction diagnostic into a parameter-fitted comparison.
